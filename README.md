# وب‌سایت گروه مهندسین آرنو — ARNO Website (v4.8)

سایت دوزبانه (فارسی / English) گروه مهندسین آرنو — معماری، اجرا، توسعه و آموزش.
استاتیک و بدون بک‌اند؛ انیمیشن‌ها با GSAP + ScrollTrigger + Lenis.

## اجرا / تست
- **نسخه آنلاین:** `https://mahdiabareshi.github.io/arno-web/`
- یا فایل `index.html` را مستقیم در مرورگر باز کنید (ریدایرکت خودکار بر اساس زبان مرورگر).

## ساختار
```
index.html          ← انتخاب خودکار زبان
fa/  en/            ← ۴۱ صفحه در هر زبان (کل سایت ۸۳ فایل HTML)
assets/css/site.css + admin.css
assets/js/site.js   + admin.js
assets/js/vendor/   ← gsap, ScrollTrigger, lenis
```

## پنل مدیریت (نسخه آزمایشی)
- **ورود مخفی:** ۴ ضربه‌ی سریع و پشت‌سرهم روی لوگوی ARNO در بالای سایت → صفحه‌ی کد → کد تستی: **۱۲۳۴**
- بخش‌ها: داشبورد، محتوای سایت، مدیریت ۸۲ صفحه، مقالات، پروژه‌ها، پیام‌های فرم تماس، ظاهر و تم، تنظیمات
- **ساخت مقاله / پروژه جدید:** فرم کامل مطابق ساختار واقعی صفحات + منوی سئو (عنوان/توضیح متا، کلمات کلیدی و هشتگ‌ها، تصویر OG، slug، زبان) + پیش‌نمایش زنده + دانلود فایل HTML آماده‌ی انتشار + ذخیره پیش‌نویس
- **ناوبری موبایل:** نوار شناور پایین صفحه (خدمات، درباره آرنو، خانه، پروژه‌ها، مقالات) + منوی کشویی خدمات؛ منوی همبرگری فقط آکادمی، تماس، مشارکت و توسعه را نگه می‌دارد
- تغییرات نسخه آزمایشی در `localStorage` مرورگر ذخیره می‌شود؛ اتصال به سرور در نسخه‌ی نهایی فعال خواهد شد.
